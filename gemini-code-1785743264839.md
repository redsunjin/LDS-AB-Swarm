# Project: Low-Cost Defensive Swarm Aerial Barrier (LDS-AB)

## 1. Project Overview
- **Goal:** Develop a low-cost defensive drone swarm algorithm and control system to intercept low-altitude invading threats (e.g., cruise missiles, kamikaze drones) by forming a dynamic 3D aerial net/barrier.
- **Key Strategy:** Hardware minimization via software intelligence. Individual drones are ultra-cheap (~$150-$200) pop-up kinetic effectors without expensive optical sensors/cameras.

## 2. System Architecture & Constraints
- **Hardware Strategy:**
  - No optical cameras on individual drones (cost reduction).
  - Sensors on board: IMU, UWB (Ultra-Wideband for relative positioning/mesh), basic ToF proximity sensor.
  - Propulsion: High-thrust FPV frame designed for short-burst pop-up capability (5-10 min flight time).
- **Control Strategy:**
  - **External Guidance:** Ground Control Station (GCS) or external sensor system feeds target trajectory data to the swarm.
  - **Hybrid Swarm Control:** Global path allocation by C2 + Fully distributed local mesh formation (APF / Voronoi).
  - **GPS-Denied Support:** UWB-based local mesh stabilization under jamming environments.

## 3. Core Software Modules to Develop
1. **Threat Prediction & Mesh Geometry Module:** Calculates intercept geometry and generates 3D grid nodes based on incoming threat velocity/uncertainty.
2. **Distributed Swarm Control & Self-Healing Module:** 
   - Position maintenance using Artificial Potential Fields (APF) / Reynolds Boids.
   - Self-healing algorithm: Instantly re-balances grid holes if a drone fails or is destroyed.
3. **Terminal Convergence Intercept Module:** Proportional navigation / local convergence logic when threat enters the barrier zone.
4. **Simulation Environment:** ROS 2 (Humble/Jazzy) + Gazebo / AirSim multi-drone physics simulation setup.

## 4. Current Phase Objectives (Phase 1: Simulation & Algorithmic PoC)
- Build a Python/C++ simulation prototype operating on ROS 2.
- Implement dynamic 3D Grid Generation algorithm reacting to a moving target trajectory.
- Implement Self-Healing logic for grid node loss recovery (< 1.0 second reaction time).
